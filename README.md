# 🤖 Priority Flow

**Priority Flow** — это Telegram-бот, который помогает навести порядок в делах и расставить приоритеты по матрице Эйзенхауэра. Больше не нужно держать всё в голове — бот сам разложит задачи по полочкам и подскажет, за что взяться в первую очередь.

## ✨ Возможности (Версия 1.0)

- **Умное добавление задач:** Бот анализирует задачу через два вопроса («Срочно?» и «Важно?») и распределяет её по одному из 4 квадрантов.
- **Разделение по приоритетам:** Удобный просмотр невыполненных задач по категориям (Срочно/Важно и т.д.).
- **Управление прогрессом:** Отметка задач выполненными в один клик с помощью inline-кнопок.
- **Статистика:** Наглядный подсчёт общего количества задач и процента выполненных.
- **Надежное хранение:** Все данные сохраняются в базе данных SQLite, поэтому задачи не пропадают после перезапуска.
- **Дружелюбный интерфейс:** Понятный онбординг для новых пользователей.

## 🛠 Технологический стек

- **Язык:** Python 3
- **Фреймворк:** aiogram 3.x
- **База данных:** SQLite 3
